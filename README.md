# 🚀 Projeto Principal

## 💧 AcquaCEG

Sistema de monitoramento da qualidade da água baseado em IoT.

O projeto integra firmware embarcado, comunicação MQTT, backend em Python, banco de dados PostgreSQL e aplicações para visualização dos dados coletados em tempo real.

Tecnologias utilizadas:

- Arduino Uno R4 WiFi
- ESP32
- C/C++
- Python
- FastAPI
- PostgreSQL
- MQTT
- Node-RED
